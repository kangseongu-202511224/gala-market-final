# GALA MARKET - 1단계 시연 사이트

경제인의 밤 모의투자대회 참가자용 프론트엔드 기초 버전입니다.

- `index.html`: 화면 구조
- `styles.css`: 밝고 간결한 모바일 금융 앱 디자인
- `app.js`: 종목 8개, 뉴스, 종목 조회, 시연용 매수·매도, 보유자산 UI

## 실행
세 파일을 같은 폴더에 놓고 `index.html`을 브라우저에서 열거나 GitHub Pages로 배포합니다.

## GitHub Pages 설정
Repository → Settings → Pages → Deploy from a branch → main → /(root) → Save.

## 중요한 제한
실제 다중사용자 모의투자 시스템이 아닙니다. 주문/현금/보유 주식은 브라우저 메모리에만 저장되며 새로고침 시 초기화됩니다. 실시간 공유, 참가자 인증, 관리자 화면, 4라운드 엔진, 뉴스 A/B 결과 및 주가 무작위 생성, 랭킹은 이후 Supabase 서버 연동 단계에서 추가해야 합니다.

초기 가격과 차트는 시연 데이터입니다. 뉴스는 가상 미국 대통령 선거 설정이며 실제 정치 뉴스가 아닙니다.
